Endpoint agent reliability release: upgrades from the old 32-bit installation now copy any missing tray configuration, repoint both SYSTEM scheduled tasks to the current 64-bit Program Files executable, confirm the new agent is running, and then remove only the obsolete x86 files and Programs and Features entry without changing enrollment or anything under ProgramData. The notification-area tray also returns to signed-in users after manual, automatic, Intune, and RMM updates run as SYSTEM. The endpoint agent list and ticket endpoint panel now show each device's reported agent version and last check-in time, with clear flags when an update is needed or a device has not checked in for more than 5 minutes. No database schema changes.
