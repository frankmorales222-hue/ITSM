# End-user guide

Sign in, choose Start a request, then select the plain-language request type that best fits. Add a short summary, useful details, and an affected asset when relevant. Do not enter passwords, medical information, Social Security numbers, or other sensitive data.

My Requests shows open, waiting, resolved, and closed work. Open a request to read its public timeline and reply. Internal IT notes are never shown. When IT resolves a request, confirm it is fixed or reopen it within seven days if help is still needed. Active announcements appear on the home page.
