# Technician guide

The Overview prioritizes your active work, unassigned work, and SLA risk. Work Queue views isolate assignment, priority, SLA, and waiting states. Open a request to see the requester conversation and accountability panel.

Use Public reply for information the requester should see; it sends a user notification. Use Internal note for operational context that must not reach the requester. Restricted notes require manager or administrator authority. When changing priority, provide a reason. When resolving a ticket, record a clear resolution summary. Waiting statuses should identify who owns the next action and why.

Bulk controls allow selected tickets to move to a shared status. Search is authorization-scoped and includes ticket number, subject, description, requester, email, category, employee, and asset identifiers through their relevant directories.
