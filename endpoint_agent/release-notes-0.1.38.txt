Northstar Endpoint Agent 0.1.38 restores the notification-area tray immediately after manual, automatic, Intune, and RMM installs that run as SYSTEM. Setup now registers and invokes an on-demand, least-privilege BUILTIN\Users tray-launcher task for signed-in sessions, while retaining the Startup shortcut for future sign-ins. The launcher remains idempotent and permits only one tray process per Windows session. Uninstall removes the new task, and tray files are replaced immediately without reboot-delayed restart replacement.
