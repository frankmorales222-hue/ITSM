Northstar Endpoint Agent 0.1.39 completes upgrades from legacy 32-bit installations. Setup copies a missing tray configuration, safely repoints the existing SYSTEM scheduled tasks to the current 64-bit Program Files executable while preserving their arguments, and removes only the obsolete x86 files and WOW6432Node uninstall entry after the new agent is confirmed running. Machine enrollment, credentials, and all data under C:\ProgramData\NorthstarEndpointAgent remain unchanged. This release also includes the 0.1.38 interactive tray-launcher fix for installs and updates run as SYSTEM.
